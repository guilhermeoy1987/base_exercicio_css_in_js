# Projeto Estilização com Styled Components - EBAC

Este repositório contém exercícios práticos focado no uso de CSS-in-JS dentro do ecossistema React, utilizando a biblioteca Styled Components.

## O que foi desenvolvido:
* **Componentes Estilizados:** Criação de elementos de interface com estilos encapsulados.
* **Estilização Dinâmica:** Implementação de lógica de design baseada em propriedades (props).
* **Gestão de Temas:** Organização de variáveis globais de estilo para manter a consistência visual.
* **Manutenibilidade:** Uso de técnicas modernas para evitar conflitos de CSS global.

## Tecnologias:
* React.js
* Styled Components
* JavaScript (ES6+)
* Git / GitHub
